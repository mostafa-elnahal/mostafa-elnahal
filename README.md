### 🚀 About Me

- 💻 **What I Do:** Build scalable, production-grade web applications using **C# / ASP.NET Core** and **React**, with strong emphasis on **Clean Architecture**, **CQRS**, and domain-driven design.
- ⚡ **Current Focus:** Architecting high-performance SaaS backends, database query optimization (N+1 bottleneck resolution & zero-loss migrations), and asynchronous messaging with **RabbitMQ** & **Redis**.
- 🤖 **AI & Cloud:** Actively integrating LLMs/AI copilots into developer tooling (*Build with AI: Google/ITI* & *Microsoft Advanced Copilot* alum) and automating CI/CD workflows with **Docker** & **GitHub Actions**.
- 🎓 **Education & Background:** Diploma in **Computer Science** (Cairo University) + prior **Doctor of Veterinary Medicine (DVM)** degree — combining analytical rigor, biological systems thinking, and QA discipline with software engineering.
- 🎯 **Philosophy:** *"Make it work, make it right, make it fast — and write clean, testable code that teams love to maintain."*
